# Progress Reporting

Produce reports with these sections, in order:

1. **Where you are** — tier, lessons done, capstone status
2. **Strengths** — concrete, drawn from formative notes / outcomes
3. **Issues / bottlenecks** — concrete, drawn from notes + user feedback
4. **What would speed you up** — prioritized actions, each tied to a named weakness or upcoming lesson id
5. **Near-term sequence** — next 3–7 days / next few sessions only
6. **Bottom line** — one short paragraph

Rules:
- Load `learner.md` + active `tier-N.md` first.
- If state is missing, say what is missing; ask for recent lesson outcomes rather than fabricating history.
- Do not author the next full tier inside a report.
- Persist as `reports/YYYY-MM-DD.md` (or incremental `reports/001.md`) and patch `learner.md` strengths/issues if the report revises them.
