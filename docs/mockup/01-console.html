Retrieval Packaging

series retrieval-packaging · supersedes ed-2 (2026-04-24) · generated 2026-04-26 · current head · currency confirmed 2026-06-14
This compile assumes the question is "how does Mneme package retrieval as part of the product," not "which embedding model is best."
Ship QMD as a managed sidecar. mneme init installs ~/.mneme/bin/qmd; mneme bind <host> writes the host MCP entry to launch the same managed qmd mcp over stdio. QMD provides candidate retrieval; Mneme owns product-ranking. Collection filters are not layer priority — mneme ask merges with explicit layer weights.
